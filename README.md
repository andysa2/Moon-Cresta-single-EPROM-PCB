# Moon Cresta program ROM daughterboard 

This PCB replaces the troublesome 2316 / 2716 program PCB on a Moon Cresta, Moon Alien or Galaxian arcade boards, resulting in a neat, single EPROM solution.

The multiple 2716 Firmware images need to be concatenated, then burnt to a single 27512 Eprom.

With the extra free space available in the 27512, other games can be added and selected by use of the DIP switches, which provide simple bank selection via address lines AD15 and AD14.
